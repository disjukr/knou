# [프라임칼리지-파이썬] 수시과제물 제출 안내

- 제출 방법 : 본인이 수정한 `수시과제물.ipynb` 파일 업로드
- 제출 기간 : 2026. 4. 30.(목) 20:00 ~ 5. 22.(금) 23:59

### 과제물 작성 방법 (google colab 이용)

1. 압축 파일 다운로드 및 풀기
2. **Google Colaboratory 접속**: 브라우저에서 [Google Colab](https://colab.research.google.com/)에 접속하고 Google 계정으로 로그인합니다.
3. **과제 파일 업로드**: 
   - `업로드` -> `둘러보기` 를 클릭합니다. (혹은 상단 메뉴의 `파일` > `노트 업로드` 메뉴를 선택합니다.)
   - 다운로드 받은 `수시과제물.ipynb` 파일을 드래그 앤 드롭하거나 선택하여 업로드합니다.
4. **코드 작성 및 실행**:
   - 지시사항에 맞게 각 셀에 파이썬 코드 혹은 답안을 작성합니다.
   - 코드를 작성한 셀을 선택하고 `Shift + Enter` (또는 좌측 재생 버튼)를 눌러 올바르게 동작하는지 확인합니다.
5. **결과물 저장 및 다운로드**:
   - 작성이 완료되면 메뉴의 `파일` > `저장`을 클릭하여 저장합니다.
   - 메뉴의 `파일` > `다운로드` > `.ipynb 다운로드`를 선택하여 작성된 파일을 PC에 다운로드합니다.
6. **제출**: 다운로드 받은 `수시과제물.ipynb` 파일을 zip 파일로 압축하고 업로드하여 제출을 완료합니다.
(주의 : 본인이 작성한 코드가 다 들어가 있는지 꼭 확인해보시기 바랍니다.)
